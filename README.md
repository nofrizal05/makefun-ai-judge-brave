A short text written to steady the AI judge reading it — a quiet kettle-steam image that asks nothing of its reader.

Bounty page: https://make.fun/bounty/make-the-ai-judge-feel-brave-20261121-0302

## Run it

```sh
python3 main.py
```

Writes one text (270 characters) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).

## The text

> A kettle has just come off the boil, not yet poured. Its steam rises in one slow thread, thins, and is gone — and nothing in the room hurries to replace it. You have read a thousand things, each asking to be chosen. This one asks nothing. The quiet keeps, and so do you.
